# Materials AI Platform

Evolutionäres Lernprojekt: von KI-Grundlagen zu spezialisierter Engineering-KI
für Werkstoffwissenschaft (Generative Materials Science, Lebensdauerberechnung,
Kerbfaktorermittlung bei Schweißnähten).

Monorepo-Struktur: jedes Modul ist eine isolierte Lektion unter `modules/`,
orchestriert via Docker Compose. Python (PyTorch) für die Logik, Streamlit für die UI.

- `modules/01_single_neuron/` — Das einfachste Neuron: Werkstoffkennlinie fitten
